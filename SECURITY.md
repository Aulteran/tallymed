# Security policy

TallyMed is pre-release software for self-hosting. Do not report a vulnerability in a public issue, and never include real household data, credentials, backups or live MCP details in any report.

Use GitHub's private vulnerability reporting for this repository (**Security → Report a vulnerability**) and describe the problem with synthetic data and steps to reproduce. Reporting must be enabled by the repository owner in **Settings → Code security**; until it is, contact the maintainer through the repository's GitHub profile and ask for a private channel before sharing details.

Known gaps that are documented rather than reported: see the "Before you deploy for real" section of [docs/operations.md](docs/operations.md).
