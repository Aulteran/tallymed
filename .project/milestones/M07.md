**Predecessors** — M06  
**Specifications** — docs/security.md, docs/architecture.md and docs/marketing.md  
**Review** — Independent milestone, financial and security reviews

## Implementation

1. Complete operator deployment, upgrade, recovery, encrypted backup and restore instructions. Verify supported proxy topology.
2. Run end-to-end ledger reconciliation and restore with synthetic records. Review source notices, dependency licenses and operational controls.
3. Prepare release notes and update the site with verified stable capabilities, real synthetic-data screenshots, version and install CTA when the release exists.

## Acceptance and required verification

- Complete fresh-install, upgrade and isolated restore drills, document integrity checks and proxy/MCP negative tests.
- Record owner release decision, supported versions, exact commit, CI and recovery evidence. Publish stable copy only after release verification.
- Pass the repository checks and record exact commands and results. Link the reviewed SHA and resolve blocking findings before merge.

Update the internal status with evidence and the next action. The owner accepts the milestone after any post-merge verification.
